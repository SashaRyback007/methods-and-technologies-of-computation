# Лабораторна робота №1
**Тема:** Інтерполяція кубічними сплайнами.
**Мета:** Вивчити метод інтерполяції кубічними сплайнами та алгоритм методу прогонки для розв'язання тридіагональних систем рівнянь.

## 1. Теоретична частина
- Вихідна модель кубічного сплайна: S_i(x) = a_i + b_i(x - x_{i-1}) + c_i(x - x_{i-1})^2 + d_i(x - x_{i-1})^3.
- Рівняння неперервності 1-ї та 2-ї похідних у внутрішніх вузлах.
- Крайові умови вільного сплайна: S_1''(x_0) = 0, S_n''(x_n) = 0.
- Формули прямої та зворотної прогонки.

## 2. Параметри експерименту
- Трансцендентна функція: f(x) = sin(x) * exp(-0.2*x)
- Відрізок: [0.0, 10.0]
- Кількість інтервалів n = 20 (вузлів n + 1 = 21)
- Крок тонкої табуляції: N = 400 (20n)

## 3. Отримані результати
- Файл базових вузлів: data/nodes.txt
- Файл повної табуляції та відхилень: data/tabulation_results.txt
- Максимальна абсолютна похибка: ~1.2e-4

## 4. Графічні матеріали
- plots/spline_approximation.png — Порівняння точної функції та сплайна
- plots/approximation_error.png — Графік абсолютної похибки

## 5. Висновки
- Тридіагональна матриця має діагональне переважання (|beta_i| >= |alpha_i| + |gamma_i|), тому розв'язок методом прогонки є стійким.
- Кубічний сплайн забезпечує гладкість C^2 на всьому проміжку та повністю уникає осциляцій, притаманних поліномам Лагранжа на краях відрізка.
