# Звіт до лабораторної роботи (Вступної)
**Тема:** Організація робочого середовища та основи роботи з Python і Git  
**Мета:** Ознайомитися з вимогами курсу, налаштувати середовище розробки, створити репозиторій для лабораторних робіт та опанувати базові команди Git.

---

## 1. Хід виконання роботи

1. **Налаштування середовища:**
   - Перевірено встановлення інтерпретатора Python: `python --version`.
   - Налаштовано робочий простір у редакторі коду VS Code.

2. **Організація структури репозиторію:**
   - Ініціалізовано систему контролю версій Git командою `git init`.
   - Створено папку `lab0` для вступної роботи та виділено директорію `lab1` під наступні завдання курсу.

3. **Реалізація програми:**
   - У файлі `lab0/main.py` написано програму виведення повідомлення:
     ```python
     def main():
         print("Hello, world")

     if __name__ == "__main__":
         main()
     ```
   - Програму протестовано в терміналі за допомогою команди `python lab0/main.py`.

4. **Фіксація змін у Git:**
   - Додано змінені файли до індексу та створено коміт:
     ```bash
     git add lab0/
     git commit -m "Lab0: Setup environment and Hello World"
     ```

## 2. Відповіді на контрольні питання

**1. Що таке чисельні методи?**  
Це алгоритмічні способи наближеного розв’язування математичних задач за допомогою ЕОМ у випадках, коли аналітичний розв'язок знайти складно або неможливо.

**2. Які типи задач розв’язуються чисельними методами?**  
- Розв'язування систем лінійних і нелінійних рівнянь.
- Інтерполяція та апроксимація функцій.
- Чисельне диференціювання та інтегрування.
- Задачі оптимізації.
- Розв'язування звичайних диференціальних рівнянь та рівнянь у частинних похідних.

**3. Які переваги NumPy?**  
- **Швидкодія:** базові операції реалізовані мовами C/Fortran, що прискорює обчислення у рази порівняно зі стандартними списками.
- **Векторизація:** можливість виконувати математичні операції над цілими масивами без використання явних циклів `for`.
- **Ефективність пам'яті:** дані зберігаються компактно у неперервних блоках пам'яті з фіксованим типом даних.
- **Функціональність:** наявність широкого набору функцій лінійної алгебри, перетворень Фур'є та генераторів випадкових чисел.

**4. Для чого використовується Git?**  
Для контролю версій файлів проєкту, відстеження змін у коді, можливості повернення до попередніх станів, роботи в паралельних гілках та взаємодії з віддаленими репозиторіями (GitHub, GitLab).

**5. Чому лабораторні необхідно зберігати у системі контролю версій?**  
- Для збереження історії поетапного написання коду.
- Для захисту від випадкової втрати чи пошкодження файлів.
- Для зручності організації структури «один курс — один репозиторій» з ізоляцією кожної роботи в окремих підкаталогах (`lab0`, `lab1`, ...).
